# Полевой справочник DayZ

Небольшой русскоязычный сайт с практическими гайдами по выживанию в DayZ. Это статический сайт: HTML, CSS и JavaScript, без сборки и внешних зависимостей. Поиск, фильтры, просмотр и редактор гайдов работают в браузере.

## Запуск локально

Запусти локальный статический сервер из этой папки:

```powershell
python -m http.server 8000
```

Затем открой http://localhost:8000. Сервер нужен, чтобы браузер мог загрузить `guides.json`.

## Добавление и публикация гайда

1. Открой сайт и нажми **Добавить гайд**. Заполни название, тему, описание и разделы, затем сохрани черновик. Черновики хранятся только в браузере и на устройстве, где ты их создал.
2. Нажми **Скачать guides.json**. Файл содержит все добавленные гайды, включая уже опубликованные.
3. На GitHub открой репозиторий сайта, выбери **Add file → Upload files** и загрузи скачанный `guides.json` в корень репозитория, заменив существующий файл.
4. Сохрани изменение в ветку `main`. После успешного запуска GitHub Actions сайт обновится, а новый гайд станет доступен всем посетителям.

Форму можно открыть и заполнить с телефона. Для публикации нужен доступ к репозиторию GitHub. До загрузки файла в репозиторий черновик не виден на других устройствах и другим посетителям. Если GitHub Pages уже опубликован, достаточно открыть сайт по его ссылке; если нет — сначала настрой публикацию по инструкции ниже.

## Публикация через GitHub Pages

В репозитории уже есть workflow `.github/workflows/pages.yml`: после публикации в ветку `main` он автоматически выкладывает сайт в GitHub Pages.

1. Создай пустой репозиторий на GitHub.
2. В этой папке открой PowerShell и выполни команды, подставив адрес своего репозитория:

   ```powershell
   git init
   git add .
   git commit -m "Create DayZ field guide"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPOSITORY.git
   git push -u origin main
   ```

3. В настройках репозитория открой **Settings → Pages** и выбери источник публикации **GitHub Actions**, если GitHub не включил его автоматически.
4. Дождись завершения workflow **Deploy to GitHub Pages**. Ссылка на опубликованный сайт появится в настройках Pages и в окружении `github-pages` на вкладке **Actions**.

Все исходные файлы сайта хранятся в репозитории; GitHub Pages публикует их автоматически при каждом обновлении ветки `main`.

## Структура

- `index.html` — разметка страницы.
- `styles.css` — оформление и адаптация для мобильных устройств.
- `app.js` — встроенные гайды, поиск, фильтры, редактор и локальные черновики.
- `guides.json` — опубликованные пользовательские гайды.
- `.github/workflows/pages.yml` — автоматическая публикация на GitHub Pages.

Сайт — фанатский проект, не связанный с Bohemia Interactive. Игровые механики могут меняться между версиями и серверами.
